# 💈 Barber Shop

Aplicação web de barbearia desenvolvida com tecnologias modernas do ecossistema JavaScript. O sistema permite autenticação com Google, visualização de serviços e uma interface responsiva e intuitiva.

## 🚀 Tecnologias utilizadas

- Next.js
- TypeScript
- Tailwind CSS
- PostgreSQL
- Prisma ORM
- NextAuth (login com Google)

## ✨ Funcionalidades

- Autenticação com conta Google
- Integração com banco de dados PostgreSQL
- Gerenciamento de dados com Prisma ORM
- Layout moderno e responsivo
- Interface otimizada para desktop e mobile

## 📱 Responsividade

O projeto foi desenvolvido com design responsivo, garantindo uma boa experiência em:

- Celulares
- Tablets
- Desktops
